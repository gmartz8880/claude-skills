# Reference Library Index

These are supplementary scholarly sources the user provided to sharpen this skill's handling of European historical texts and related linguistic background. They are supporting/contextual material, not a replacement for the core workflow in SKILL.md. Read the relevant file (or just the applicable section, using the `read` tool's offset/limit) only when a translation task actually touches that topic — don't load all of them for every request.

## early-modern-english-c1500-c1800.pdf
**Topic:** History of English, c. 1500–c. 1800 (Great Vowel Shift, Renaissance English, printing/standardization, Shakespeare-era spelling and pronunciation).
**Use when:** Translating/transcribing English-language manuscripts or printed texts from this period. Helps explain why spelling looks archaic or inconsistent, and how period pronunciation likely differed from the modern reading of the same spelling (e.g. words spelled the same as today were often pronounced quite differently pre-Great Vowel Shift). Useful for giving the user context notes, not just a bare translation.

## old-celtic-languages-meid.pdf
**Topic:** Wolfgang Meid's survey of old Celtic languages and scripts — Gaulish, Celtiberian (and the Iberian script it borrowed), Old Irish (including legal tracts and Ogham-era material), Early Welsh poetry, Old Breton glosses.
**Use when:** The user's image shows Continental Celtic (Gaulish/Celtiberian) inscriptions, Ogham strokes, or early Insular Celtic (Old Irish/Old Welsh/Old Breton) manuscript text. Extends this skill's "European texts" and general ancient-inscription coverage to Celtic material, which isn't otherwise called out in the main script-specific notes.

## teaching-italian-vernacular-16th-c-lorenzon.pdf
**Topic:** Massimiliano Lorenzon's dissertation on how the Italian vernacular ("fiorentino"/"toscano"/"volgare"/"italiano") was taught and learned in 16th-century Western Europe, including grammars, textbooks, manuscript marginalia/annotation practices, and pedagogical methods of the period.
**Use when:** Transcribing 16th-century Italian manuscripts or printed texts, especially ones with reader marginalia/annotations — this source explains that annotation conventions were not standardized, which helps you avoid over-interpreting inconsistent markup as meaningful script.

## byzantine-iconography-14th-15th-c.pdf
**Topic:** General iconographic and stylistic changes in Byzantine/Slavic religious art during the 14th–15th centuries (hesychasm and humanism as competing influences on style).
**Use when:** An illuminated manuscript or icon inscription's accompanying art style needs dating/context — stylistic cues (figure proportions, color palette, composition) described here can help corroborate or refine a date estimate for a Byzantine-sphere manuscript, which in turn helps you pick the right script/language conventions for that period.

## old-prussian-language-revival-szatkowski.pdf
**Topic:** Piotr Szatkowski's sociolinguistic study of modern Old Prussian language revivalists, with background on the scarce surviving Old Prussian written monuments (14th-century glossary, 16th-century catechisms, place-name/personal-name corpora).
**Use when:** The user's text is identified as Old Prussian or another small/extinct Baltic language monument. Mainly useful as background on how little source material exists and where it comes from — manage expectations about certainty accordingly.

## schultens-primeval-language-eskhult.pdf
**Topic:** Josef Eskhult's history-of-linguistics article on Albert Schultens (1686–1750) and 18th-century debates about whether Hebrew was the "primeval language" and how Semitic languages relate to each other.
**Use when:** Providing historical/etymological context for a Hebrew, Aramaic, or Arabic text's place in the broader Semitic language family — this is intellectual-history background, not a decipherment aid, so use it only for contextual notes, not for reading unfamiliar signs.
