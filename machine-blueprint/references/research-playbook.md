# Research playbook - researching ANY machine (and its poverty buttons)

Goal: gather the real facts behind the drawing set and manual - identity, dimensions, specs, systems,
procedures, parts - plus (when relevant) every factory switch blank / deleted option and how to enable it.
Sources in order: manufacturer manuals & spec sheets, official parts catalogs, service bulletins (NHTSA TSBs
for vehicles), standards bodies, then reputable owner forums. Record a dated source list.
Search the web for every fact below; do not answer from memory. Note the date checked.

## 1. Pin down the machine
- From a VIN: decode it (NHTSA vPIC decoder: vpic.nhtsa.dot.gov) for year/model/trim/engine/plant.
- From a model number / serial (mowers, tractors, equipment): find the manufacturer's model page and
  operator's manual (parts lookup sites like the maker's own parts portal, PartsTree, Jacks, etc.).
- From a part number: search it in quotes to find the vehicle family and the parts diagram it belongs to.
- If trim, cab, drivetrain or engine is unknown and changes the answer, ask once (or infer from the photo).

## 2. What the higher trims/options get (cars and trucks)
- Brochure / spec-sheet archives, manufacturer press releases for that model year, Edmunds/KBB/Auto123
  "features & specs" per trim. Build a table: feature -> base / mid / top trim.
- Owner forums (search "<model> blank switches", "<model> poverty buttons", "<model> switch blank what for").
- Official parts catalogs (dealer EPC sites) list switches with notes like "with heated seats", "without
  sonar", "Limited" - these notes are the best proof of which slot is which.

## 3. Equipment (mowers, tractors, UTVs, boats)
- Blanks are usually option kits: lights, PTO / hour meter, cruise, hydraulics (3rd function), work lights,
  12 V outlet, seat heat, cab heater, trailer/brake, mid-mount or rear PTO, reverse-mowing override (RIO).
- Use the operator's manual control-panel page + the parts diagram "dash / console / control panel".
- Accessory kits from the manufacturer usually ship with the exact switch and harness - list the kit number.

## 4. Part numbers and pictures (required at the end of every run)
- Get exact numbers from dealer parts sites (prices change - date them). Include superseded numbers and
  left/right, vented, colour variants; tell the user to confirm by VIN/serial with a dealer.
- In the chat reply, show a picture of each main part (image search "<part number> <part name>").
  Do not copy product photos into the PDF/blueprint (copyright); describe instead, or draw it.

## 5. Accuracy checks before drawing
- Cross-check each slot assignment with two sources (parts catalog note + forum/owner photo) where possible.
- Mark anything uncertain on the sheet ("position varies by build - verify") rather than guessing silently.
- Safety items (airbags/SRS, fuel, hydraulics, PTO, brakes) always get a CAUTION box in the document.

## 6. Dimensions and geometry (for drawing any machine)
- Overall dimensions: manufacturer spec sheet / brochure / manual. Component sizes: parts catalogs, service manual.
- From photos: scale from a known dimension (wheel size, bolt pattern, rated shaft diameter) and mark APPROX.
- Owner photo supplied -> trace layout and proportions from it; say "traced from owner photo".

## 7. Procedures, specs and torque values
- Service manual / owner's manual first; then TSBs; then reputable repair guides. Put the value AND the source.
- If a value can't be found, write "per service manual" instead of guessing.
